# AI Escape Workshop Kit

医療教育者が、文章・対話・画像・動画の4形式を横断して生成AIを体験する、90分のワークショップ教材です。静的Webアプリのため、サーバーや参加者アカウントは不要です。

原案：三原 弘・古堅 裕章・菊原 美緒。2025年に実施したJMeLプレワークショップの構成をもとに、第三者が再利用できるよう再設計しています。

## 特徴

- 4つのミッションとスタータープロンプト
- ミッションごとの15分タイマー
- 端末内だけに保存される進捗チェック
- 投影モード、印刷用進行ガイド、オフラインキャッシュ
- 2025年ワークショップで提示した合成症例、サンプルポスター、動画代表フレーム
- 個人情報を収集しない設計

## 公開方法

GitHub Pages用のファイルは `docs/` にあります。リポジトリの **Settings → Pages** で、`main` ブランチの `/docs` を公開元に設定してください。

## ローカル確認

`docs/` を任意の静的HTTPサーバーで配信してください。Service Workerは `file://` では動作しません。

## 安全上の注意

本教材は教育目的であり、診断・治療には使用できません。実在する患者・学生・職員の情報、未公開研究データ、施設の秘密情報を外部の生成AIへ入力しないでください。成果物を公開する場合は、授業内共有とは別に公開範囲を明示して同意を得てください。
